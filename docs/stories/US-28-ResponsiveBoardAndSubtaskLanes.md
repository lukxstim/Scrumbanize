# US-28: Responsive Board-Layout & Subtask-Swimlanes

## User Story
Als **Benutzer**
möchte ich **ein responsive gestaltetes Kanban-Board nutzen, erledigte Aufgaben ausblenden und Unteraufgaben separat betrachten können**,
damit **der Bildschirmplatz auf PCs optimal genutzt wird und das Board übersichtlich bleibt**.

---

## Kontext & Zweck
Auf breiten Desktop-Bildschirmen bleibt Platz ungenutzt, und mit vielen erledigten Aufgaben und Unteraufgaben wird das Board schnell unübersichtlich.

---

## Akzeptanzkriterien

### 1. Responsive Layout
- [x] Das Board-Grid passt sich dynamisch an breite Desktop-Bildschirme an.

### 2. Filter & Unteraufgaben
- [x] Erledigte Aufgaben lassen sich über einen Filter-Toggle ein- und ausblenden.
- [x] Unteraufgaben können optional in einen eigenen Board-Abschnitt bzw. eine Unterzeile einsortiert werden.
